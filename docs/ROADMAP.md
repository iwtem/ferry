# 渡 Ferry 产品规划（Roadmap）

> 定位：原生 Swift + SwiftUI 打造的轻量级 macOS 大模型翻译工具——不占 Dock 栏、常驻菜单栏、即开即译、顺手无打扰。

## 已完成基础能力（V1）

- [x] **多形态窗口**：菜单栏快译弹窗、双栏独立大窗口、桌面悬浮迷你小窗、双击 `⌘C` 类 DeepL 悬浮卡片
- [x] **多服务商流式翻译**：DeepSeek、阿里百炼（DashScope）、自定义 OpenAI 兼容（含本地 Ollama），支持自动拉取 `/models`
- [x] **智能查词模式**：单词 / 短语自动切换紧凑词典释义（音标、词性、释义、例句）
- [x] **多引擎朗读发音**：macOS 本地增强语音（`AVSpeechSynthesizer`）+ 云端 TTS（百炼 / OpenAI 兼容）
- [x] **系统与体验**：中英双语界面、浅色/深色外观跟随、开机自动启动、最近 50 条翻译历史

---

## 迭代规划

### P0 · 截图 OCR 翻译 & 应用内自动更新（优先落地）
- [x] **本地离线 OCR 识别**：基于 macOS 原生 `Vision`（`VNRecognizeTextRequest`）识别中/英/日/韩等多语种文字，零额外接口费用
- [x] **智能排版重组**：按阅读顺序还原文本行，自动处理英文连字符断词与段落换行，避免截图/PDF 译文碎裂
- [x] **全局快捷键与多入口**：默认 `⌥⇧S`（支持自定义）全局拉框截图，同时支持菜单栏弹窗、右键菜单、大窗口按钮触发，以及大窗口「粘贴并翻译」直接识别剪贴板截图
- [x] **屏幕录制权限引导**：在设置页集成权限检测与一键跳转
- [x] **应用内自动更新（GitHub Releases）**：后台定时/启动自动检测新版本、静默下载并校验 SHA-256、弹窗/设置页一键「重启并更新」（原子替换 `.app` 并保留签名与系统权限），配套 `Scripts/release.sh` 与 `Scripts/deploy_local.sh`

### P1 · 交互顺手度与写作场景
- [x] **翻译 / 写作润色模式切换**
  - 在 `TranslationPrompt` 中增加场景预设：`标准翻译`、`地道润色`、`语法纠错`、`职场简洁`、`学术表达`（写作模式在目标语言为「自动」时默认保留原文语种，选择具体语种时直接跨语种翻译并润色）
  - 进阶：支持在任意 App 输入框中通过双击 `⌘C` 或全局快捷键 `⌥⇧R`（不污染剪贴板）唤起悬浮卡片，点击「替换原文」或按 `⌘⏎` 一键将译文/润色结果写回原输入框并自动还原剪贴板
- [ ] **全局快捷键体系扩展**
  - 一键呼出菜单栏快译（如 `⌥Space`）、一键打开大窗口

### P2 · 阅读与学习效率
- [x] **PDF / 论文阅读优化**：可选开关，自动合并 PDF 复制带来的多余硬回车与 `algo-\nrithm` 连字符断词（保留空行分段、列表项与代码块）
- [ ] **个人术语表（Glossary）与自定义指令**：支持维护专有名词译法（或指定保留原文），自动注入翻译系统提示词
- [ ] **生词本 / 收藏夹与历史搜索**
  - 翻译/查词卡片支持一键星标收藏
  - 历史侧边栏支持关键词搜索、仅看收藏，以及导出为 Markdown / CSV（适配 Anki 或笔记工具）

### P3 · 进阶体验与生态联动
- [ ] **单次快速切模型重译 / 双模型对比**：日常用快模型秒译，难句可在结果卡片一键用强模型重译
- [ ] **翻译结果 LRU 缓存**：相同词句重复查询秒出结果、节省 Token
- [ ] **macOS 系统「服务」菜单 & URL Scheme (`ferry://`)**：支持右键菜单调用以及与 Raycast / Alfred / 快捷指令联动
- [ ] **原生桌面小组件（WidgetKit）**：基于已解耦的 `FerryCore` 与 App Group 共享数据，展示最近翻译与快捷入口
